# Factur-X / ZUGFeRD Test Data

Well-formed UN/CEFACT Cross Industry Invoice XML with synthetic seller, buyer, and totals for e-invoicing tests.

Free to use under **CC0-1.0** (public domain dedication, no attribution required).

## Files

- `factur-x-small.json`
- `factur-x-small.csv`
- `factur-x-medium.json`
- `factur-x-medium.csv`
- `factur-x-large.json`
- `factur-x-large.csv`

Each size ships as JSON and CSV. The data is deterministic: the same size always
produces the same rows.
